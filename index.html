01

What it is

Most reverse-engineering courses point you at malware or crackmes. Nobody teaches reading an undocumented game protocol off the wire.

DRIFTLIGHT is a tiny multiplayer arena game written for one purpose — to be reverse engineered. You get the stripped server and client binaries and a recorded session (1,976 packets). No protocol documentation exists.

You will create it.
